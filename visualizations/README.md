# Benchmark & Profiling Visualizations

Complete visual analysis of three optimization techniques for DiT inference.

## Overview

**9 publication-quality charts** organized in two categories:

### Part 1: Benchmark Results (Charts 1-5)
End-to-end performance measurements showing speedups

### Part 2: Profiling Metrics (Charts 6-9)  
Hardware-level insights revealing *why* optimizations work

### Example: CUDA Graphs

**Benchmark perspective (Chart 3):**
- Eager: 105.60ms
- Graph: 30.47ms
- Speedup: 3.47x ✓

**Profiling perspective (Chart 8):**
- Kernel execution: 30.47ms (same for both)
- Host overhead: 75.13ms (eager only)
- Insight: **Overhead was the bottleneck, not compute**

## Key Insights Summary

### 1. KV Caching
- **Speedup:** 1.88x (Euler) / 0.75x (MPC batch)
- **Why:** Eliminates redundant prefill computation
- **Hardware:** 36.9% fewer memory allocations
- **Best For:** Single inference, long context reuse

### 2. CUDA Graphs
- **Speedup:** 3.47x (short ODE) / 2.19x (batch)
- **Why:** Eliminates host-device synchronization
- **Hardware:** 71% of eager time is overhead
- **Best For:** Batch planning, fixed shapes

### 3. Ring Buffer
- **Speedup:** 1.29x (isolated) / 1.01x (amortized)
- **Why:** Avoids memcpy operations on context shifts
- **Hardware:** 36% fewer CPU ops, same memory
- **Best For:** Frequent context window updates
